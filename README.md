# Zinlo

Рабочий MVP для совместного обучения: React, Node.js 24, SQLite. Интерфейс на английском использует выбранный синий дизайн Project Studio. Данные сохраняются сервером; в обычном приложении нет автоматически созданных людей или команд.

## Запуск

Требуется Node.js 24 или новее.

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Сервер API работает на 127.0.0.1:3001. Первый запуск создаёт `data/learning-squads.sqlite`. Для проверки разных участников используйте независимые профили браузера, например обычное и приватное окно. Вкладки одного профиля используют одну гостевую сессию.

Изменения интерфейса обновляются автоматически. После изменения серверных файлов перезапустите `npm run dev`.

Собранная версия запускается одной командой сервера:

```powershell
npm run build
npm start
```

После этого открыть http://127.0.0.1:3001. При остановке сервера данные остаются в SQLite. Для переноса данных остановите сервер и скопируйте каталог `data` целиком; не удаляйте его при обновлении исходников.

## Реализованные сценарии

- Индивидуальная гостевая сессия в HttpOnly cookie, профиль, три направления и два уровня с описаниями для каждого предмета.
- Доступность по дням с несколькими интервалами, именованные часовые пояса, шаг 30 минут.
- Автоматический подбор людей, которые тоже нажали Find my teammates: одинаковый трек и уровень, совместимость всех восьми конкретных часовых окон.
- Очередь поиска с анимацией, отменой и восстановлением после обновления страницы; команда формируется автоматически при трёх совместимых участниках. Четвёртый может заполнить свободное место в автоматически собранной команде.
- Названия команд — курс и постоянный номер, например Python Foundations #001. Выход и история сохраняются.
- Серверные состояния Forming, Ready, Active, Completed и Closed; новая команда — 3–4 участника, продолжение вдвоём — только по согласию обоих.
- Главный кабинет команды и отдельные страницы Learning plan, Assignments, Team chat, Meetings, Progress и Settings. Недели и уроки имеют свои адреса; можно вернуться в кабинет или воспользоваться кнопкой браузера «Назад».
- Сохранённый чат команды с обновлением сообщений, счётчиком непрочитанных, загрузкой истории и защитой от повторной отправки. Черновик сохраняется при переходе между подразделами кабинета.
- Встроенная видеокомната для 3–4 участников без Google-аккаунтов: предварительный просмотр, готовность всей команды, микрофон, камера, режим слушателя, выход обратно в кабинет. WebRTC использует Cloudflare TURN при настройке серверных ключей.
- Выход из команды находится только в Settings → Manage my membership и требует подтверждения.
- Последовательное обучение: первая неделя доступна для подготовки сразу, следующие открываются по расписанию; новый урок требует завершения предыдущих. Проверка доступа выполняется на сервере.
- Подтверждение I’m ready для ближайшей встречи, общий список готовности и автоматический переход всей команды в одну конференцию.
- Автоматическое создание Google Meet после готовности всех участников: требуется однократное OAuth-подключение организатора. Ручная ссылка остаётся запасным вариантом и тоже открывается только после готовности команды.
- Базовая сохранённая программа и необязательная AI-адаптация с проверкой структуры и сохранением результата.
- JavaScript удалён из интерфейса, истории и подбора. Участники его прежних команд могут выбрать один из текущих курсов, сохранив имя и расписание.
- Демо-страница оплаты перед поиском: курс, состав спринта, цена $29, скидка демо и итог $0. Карта не запрашивается, платёж не создаётся.
- 24 квиза по три вопроса с серверной проверкой и повторными попытками; 12 индивидуальных недельных заданий с черновиком, чек-листом и сдачей текста или ссылки.

Заполнение состава и статусы обновляются при запросах к серверу и раз в минуту, пока сервер запущен. Время завершения — четыре календарные недели после первой встречи. Автоматическая замена участников после старта не предусмотрена. Изменение личной доступности не меняет расписание команды.

## Как найти команду

1. Нажмите Find my squad и заполните имя, курс, уровень, часовой пояс и доступность.
2. На последнем шаге нажмите **Continue to checkout**, проверьте курс и нажмите **Continue for free**. Это демооплата без списаний; кнопка запускает настоящий поиск команды.
3. Оставьте вкладку открытой и видимой. Анимация отражает поиск настоящих участников; выдуманных людей и таймера «успешного подбора» нет.
4. Как только есть минимум три подходящих человека, сервер создаст команду и покажет участников и восемь дат. Нажмите Open my squad.

Поиск получает подтверждение активности каждые пять секунд и истекает после двух минут без него. После возвращения можно запустить его снова. Cancel search отменяет только незавершённый поиск; если команда уже собралась, интерфейс покажет её. Чтобы отказаться от найденной команды, откройте Settings → Manage my membership → Leave this squad. Редактирование профиля отменяет предыдущий поиск.

Для проверки настоящего подбора нужны минимум три независимые гостевые сессии с совместимыми настройками — например обычный профиль Chrome, инкогнито Chrome и другой браузер. Пока в поиске только один или два человека, ожидание является нормальным состоянием. Главная показывает интерактивный пример результата каждого курса; полные уроки доступны внутри команды по мере открытия.

## Общение и видеозвонки

Откройте **Team chat**, напишите сообщение и нажмите Enter или стрелку отправки. Shift+Enter добавляет строку. Скрепка прикрепляет файлы и фото. Сообщения видны только нынешним участникам команды; после завершения спринта история доступна для чтения. Автоматической модерации нет.

Для звонка все участники открывают **Meetings → Open video room** у ближайшей встречи. Каждый разрешает камеру и микрофон или выбирает режим слушателя, затем подтверждает готовность. Когда готовы все участники команды, начинается соединение. **Leave call and return home** выключает локальные устройства и возвращает в кабинет, сохраняя членство в команде. Google Meet остаётся отдельной необязательной альтернативой.

Камера и микрофон требуют HTTPS (localhost подходит для разработки). Видеозвонки не записываются. Весь медиатрафик идёт между браузерами напрямую или через TURN, не через HTTP-сервер сайта. Для Cloudflare задайте на сервере `CLOUDFLARE_TURN_KEY_ID` и `CLOUDFLARE_TURN_API_TOKEN`; браузер получает только временные разрешения на два часа. Постоянный токен не включайте в Vite-переменные, Git или клиентские сборки. Поддерживается и собственный coturn через `TURN_URLS` / `TURN_SECRET`.

TURN оплачивается владельцем сервиса по условиям Cloudflare; участникам не нужны аккаунты Cloudflare или Google. Без TURN остаётся прямой WebRTC, который может не соединиться в некоторых сетях. Комната обслуживается одним Node.js-процессом; при перезапуске участники входят заново. Для горизонтального масштабирования потребуется общее хранилище сигналов.

Недельное задание — отдельный этап личного проекта: ученик сверяется с чек-листом, сдаёт результат и обсуждает его с командой. Статус сдачи не означает оценку преподавателя. Квизы проверяются сервером; человеческая или AI-проверка проектов пока не подключена.

## Учебные направления

Новые участники выбирают один из трёх курсов:

| Курс | Содержание | Результат спринта |
|---|---|---|
| Python Foundations | Основы Python с последовательным переходом от ввода и переменных к функциям и файлам | Работающий консольный трекер привычек |
| Practical AI | Использование ИИ для текстов, поиска и проверки информации, планирования и повторяемых задач | Собственный набор проверенных приёмов и рабочий процесс с ИИ |
| Everyday Spanish | Представление себя, бытовые диалоги, еда, ориентирование и договорённости | Личный разговорник и короткие практические диалоги |

Каждый курс рассчитан на четыре недели и восемь встреч. У урока есть объяснение понятий, разобранные примеры, самостоятельная и совместная практика, короткий автоматически проверяемый квиз и критерий выполнения. Для уровня «знаю основы» предусмотрено дополнительное усложнение. Интерфейс и объяснения остаются на английском; языковые примеры курса испанского — на испанском.

## Как проходить учебный план

1. Откройте **Plan**: на первом экране только четыре недели и состояние каждой.
2. Выберите неделю, затем доступный урок. Внутри урока разделы **Learn**, **Practice**, **Quiz** и **My result**.
3. Прочитайте объяснение, выполните упражнение и проверьте себя. Пример ответа раскрывается по желанию.
4. В **Quiz** ответьте на три вопроса. Для завершения урока нужны 3 из 3; при ошибке появится объяснение, затем можно попробовать снова. Успешный тест сам отмечает урок как выполненный. В **My result** можно сохранить заметки и ссылку.
5. После двух уроков откройте **Weekly assignment**. Выполните практическую работу вне сайта, вставьте текст или ссылку с пояснением, пройдите чек-лист и нажмите **Submit assignment**. **Save draft** сохраняет личный черновик; после сдачи работу видят участники, которым доступно это задание. Работу можно обновить после обсуждения.
6. В **Progress** видны уроки, число завершённых недельных заданий, ближайший шаг и четыре краткие строки недель. Чужой прогресс не блокирует ученика. Практические задания проверяет сам ученик по чек-листу; автоматической проверки кода и преподавателя нет.

Первая неделя открывается сразу при создании команды. Недели 2–4 — в момент первой встречи соответствующей недели, после уроков с квизами и сдачи предыдущего недельного задания. Сохранённая работа остаётся доступной, пропущенные открывшиеся уроки не исчезают. После завершения четырёхнедельного спринта все его материалы доступны для чтения в истории. При обновлении уже завершённые уроки и недели получают явный зачёт без выдуманных оценок: пересдавать их не требуется.

Сервер не отдаёт содержимое закрытых уроков в публичном каталоге или кабинете и отклоняет попытку сохранить их результат напрямую. Полный контракт и исключения для прежних сохранённых результатов: [PROGRESSION-CONTRACT.md](PROGRESSION-CONTRACT.md).

Practical AI не требует Python или платного API. В заданиях предусмотрены подготовленные примеры; работа с выбранным внешним ИИ-помощником зависит от условий этого сервиса. Четыре недели испанского — начальная разговорная практика, а не обещание свободного владения языком.

JavaScript Foundations полностью убран из продукта, включая старые команды и стартовые файлы. Сервер закрывает незавершённые JavaScript-спринты и освобождает их участников для выбора нового курса. Прямые ссылки на эти команды переводят бывших участников к выбору курса (или в их новую команду); старые записи остаются в базе для восстановления. AI Apps with Python остаётся доступен только прежним командам. Сохранённые учебные планы других курсов, включая прежние Python-спринты, не переписываются.

## AI-адаптация программы

Базовые программы работают без внешних сервисов. Для настоящей AI-адаптации скопируйте `.env.example` в `.env` и задайте:

```dotenv
AI_CHAT_ENDPOINT=https://your-provider.example/v1/chat/completions
AI_API_KEY=your-secret-key
AI_MODEL=your-model-id
```

Нужен провайдер с совместимым chat completions API и JSON-ответом. Перезапустите сервер после настройки. Ключ остаётся на сервере. Не вставляйте ключ в браузер, исходники, сообщения или Git. Неправильный ответ, таймаут и отсутствие настройки сохраняют доступ к базовой программе. AI не подбирает участников и не проверяет навыки. Успешно адаптированный план сохраняется; начатые задания не переписываются.

AI-адаптация программы и учебный курс Practical AI — разные функции. Курс доступен без подключения серверного AI-провайдера. В прежнем курсе AI Apps with Python сохраняются задания с бесплатным mock-провайдером; реальные API-вызовы в таких проектах требуют собственного провайдера и могут иметь отдельную стоимость.

## Готовность и Google Meet

В Overview под ближайшей встречей каждый нажимает I’m ready и подтверждает, что готов подключиться сейчас. Подтверждение открывает отдельную вкладку ожидания, а кабинет команды остаётся открытым. Пока ждём остальных, готовность можно отменить. После подтверждения всех текущих участников сервер создаёт и сохраняет одну конференцию; вкладка ожидания автоматически открывает Meet. Если браузер блокирует новую вкладку, доступна кнопка ручного входа.

После звонка закройте вкладку Meet, чтобы вернуться к открытому кабинету. Нажатие «Завершить звонок» внутри Google не передаётся нашему сайту, поэтому автоматический возврат именно по этому событию не обещается.

Для автоматического создания один участник команды подключает Google. Настройка проекта, OAuth-клиента и серверного шифрования описана в [GOOGLE-MEET-SETUP.md](GOOGLE-MEET-SETUP.md). Без настройки приложение честно показывает необходимость подключения: готовность сохраняется, но выдуманная ссылка не создаётся. Обычная регистрация в Zinlo по-прежнему не требуется. Google-подключение не восстанавливает потерянную гостевую cookie.

Готовность относится к конкретной встрече и текущему составу. Добавившийся участник подтверждает её сам; вышедшие не учитываются. Можно подтвердить готовность и раньше назначенного времени, если вся команда договорилась встретиться сейчас. Доступ к камере, микрофону и допуск в конференцию регулирует сам Google Meet.

Новые конференции создаются в режиме Open: по согласованному правилу любой обладатель Meet-ссылки может войти без запроса допуска. В самом Zinlo ссылка на ближайшую встречу по-прежнему открывается текущим участникам только после готовности всей команды. Остальные правила Google и настройки организатора сохраняются.

## Проверки

```powershell
npm test
npm run build
```

HTTP-тесты используют отдельные базы и независимые cookie, проверяют сохранение после перезапуска, конкурентное вступление, границы доступа, расписание и смену времени, жизненный цикл и AI fallback. Инъекция времени в `createApp` позволяет проверять четыре недели без ожидания.

При передаче проекта 14 ноября 2026 года: 20 из 20 HTTP-тестов прошли, production-сборка успешна. В браузере проверены анкета → отсутствие совпадений → создание команды → восемь дат → сохранение задания → обновление страницы, валидация Meet-ссылки и экран шириной 390 px. Ошибок JavaScript в проверенном сценарии не обнаружено. Тестовые данные браузерной проверки хранятся отдельно от рабочей базы.

AI проверен на тестовых адаптерах (успех, ошибка, некорректный ответ и конкурентное сохранение задания); вызов реального провайдера требует настройки и пока не проверялся.

Обновление 15 ноября 2026 года: 35 HTTP-тестов проходят (20 исходных и 15 для автоматической очереди, отмены, срока поиска, DST, гонок и миграции номеров). При старте прежняя база обновляется без сброса профилей, членства или прогресса.

В браузере также проверена новая цепочка: анкета → Find my teammates → ожидание → автоматическое формирование команды из трёх тестовых участников → восемь дат → кабинет. Результат появляется без обновления страницы; ошибок JavaScript в проверенном сценарии нет. Эта проверка использовала отдельную базу данных.

Обновление готовности и Google Meet: проходят 57 автоматических тестов, включая 15 проверок готовности и 7 проверок Google OAuth. Проверены конкурентное создание конференции, отмена готовности, изменение состава и отключение организатора, права доступа и сохранение данных. Production-сборка успешна. В браузере проверены подтверждение и отмена готовности, общий счётчик и сохранение после обновления; ошибок JavaScript нет. Через общий HTTPS-адрес проверены три независимых участника и честное сообщение при отсутствии настройки Google. Автоматические тесты OAuth и создания конференций используют адаптеры.

15 ноября 2026 года на временном HTTPS-сервере также успешно завершено настоящее OAuth-подключение организатора и проверено сохранение зашифрованного доступа. Через тот же серверный Google Meet сервис создана отдельная настоящая тестовая конференция: API вернул корректные meetingUri и space name. Эта проверка не изменяла готовность участников или запланированные встречи. Полный сценарий автоматического перехода реальной команды требует, чтобы все её участники самостоятельно подтвердили готовность.

Дополнительно проверены отдельная вкладка ожидания, отмена и повторное подтверждение готовности, сохранение кабинета, автоматическое открытие настоящей Meet-страницы после готовности 3 из 3 и отказ открывать будущую встречу. Проверка выполнена на отдельной тестовой базе; браузерных ошибок не обнаружено. ## Обновление анкеты и самостоятельного курса — 15 ноября 2026

## Если команда уменьшилась

Когда в уже собранной команде остаётся меньше трёх человек, на главной команды и в Settings появляются варианты:

- Продолжить вдвоём — требуется согласие обоих оставшихся участников.
- Продолжить самостоятельно — результаты уроков, квизов, задания и исходные даты открытия недель сохраняются, дополнительной оплаты нет.
- Найти другую команду — настоящий подбор по курсу, уровню, доступности и уже занятым часам. Старые работы остаются в истории; результаты одинаковых уроков и заданий переносятся в новую команду. Изменённые/AI-адаптированные задания не засчитываются как другие задания.
- Закрыть своё место и записать демовозврат — старые работы доступны для чтения.

На выбор даётся до 48 часов, но не позже старта ещё не начавшегося спринта или окончания текущего. Без решения команда закрывается; оставшимся участникам сохраняется запись демовозврата. Если новая команда не нашлась к этому сроку, такой же результат получает ожидающий замену участник. Добровольно вышедший ранее участник не включается в этот автоматический сценарий.

Доля возврата фиксируется при возникновении проблемы: количество ещё не начавшихся встреч / 8. Если команда изначально не собралась к старту — 100%. **В текущем продукте оплачено $0, возвращено $0; сохраняется только демонстрационная запись. Банковские переводы и платёжный провайдер не подключены.** Повторный запрос не создаёт ещё один возврат. Реальные платежи требуют отдельного провайдера и согласованных условий; сервер не выдаёт их за успешно возвращённые.

По последнему решению владельца проекта в профиле есть короткие правила уважительного общения и соблюдения договорённостей. Жалобы, рассмотрение нарушений, персональные санкции и апелляции отложены. Денежных штрафов нет.
