# Learning Squads

Рабочий MVP для совместного обучения: React, Node.js 24, SQLite. Интерфейс на английском, намеренно простой. Данные сохраняются сервером; в обычном приложении нет автоматически созданных людей или команд.

## Запуск

Требуется Node.js 24 или новее.

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Сервер API работает на 127.0.0.1:3001. Первый запуск создаёт `data/learning-squads.sqlite`. Для проверки разных участников используйте независимые профили браузера, например обычное и приватное окно. Вкладки одного профиля используют одну гостевую сессию.

Изменения интерфейса обновляются автоматически. После изменения серверных файлов перезапустите `npm run dev`.

Собранная версия запускается одной командой сервера:

```powershell
npm run build
npm start
```

После этого открыть http://127.0.0.1:3001. При остановке сервера данные остаются в SQLite. Для переноса данных остановите сервер и скопируйте каталог `data` целиком; не удаляйте его при обновлении исходников.

## Реализованные сценарии

- Индивидуальная гостевая сессия в HttpOnly cookie, профиль, три направления и два уровня.
- Доступность по дням с несколькими интервалами, именованные часовые пояса, шаг 30 минут.
- Автоматический подбор людей, которые тоже нажали Find my teammates: одинаковый трек и уровень, совместимость всех восьми конкретных часовых окон.
- Очередь поиска с анимацией, отменой и восстановлением после обновления страницы; команда формируется автоматически при трёх совместимых участниках. Четвёртый может заполнить свободное место в автоматически собранной команде.
- Названия команд — курс и постоянный номер, например Python Foundations #001. Выход и история сохраняются.
- Серверные состояния Forming, Ready, Active, Completed и Closed; минимум три и максимум четыре участника.
- Overview, Plan и Progress, восемь задач для каждого направления, личные статусы, заметки, ссылки и результаты команды.
- Подтверждение I’m ready для ближайшей встречи, общий список готовности и автоматический переход всей команды в одну конференцию.
- Автоматическое создание Google Meet после готовности всех участников: требуется однократное OAuth-подключение организатора. Ручная ссылка остаётся запасным вариантом и тоже открывается только после готовности команды.
- Базовая сохранённая программа и необязательная AI-адаптация с проверкой структуры и сохранением результата.
- HTML/CSS-заготовка для JavaScript Foundations: `/starter.html`.

Заполнение состава и статусы обновляются при запросах к серверу. Для запуска/закрытия спринта не требуется фоновый процесс. Время завершения — четыре календарные недели после первой встречи. Автоматическая замена участников после старта не предусмотрена. Изменение личной доступности не меняет расписание команды.

## Как найти команду

1. Нажмите Find my squad и заполните имя, курс, уровень, часовой пояс и доступность.
2. На последнем шаге нажмите большую кнопку Find my teammates.
3. Оставьте вкладку открытой и видимой. Анимация отражает поиск настоящих участников; выдуманных людей и таймера «успешного подбора» нет.
4. Как только есть минимум три подходящих человека, сервер создаст команду и покажет участников и восемь дат. Нажмите Open my squad.

Поиск получает подтверждение активности каждые пять секунд и истекает после двух минут без него. После возвращения можно запустить его снова. Cancel search отменяет только незавершённый поиск; если команда уже собралась, интерфейс покажет её. Чтобы отказаться от найденной команды, используйте Leave squad в кабинете. Редактирование профиля отменяет предыдущий поиск.

Для проверки нужны минимум три независимые гостевые сессии с совместимыми настройками — например обычный профиль Chrome, инкогнито Chrome и другой браузер. Пока в поиске только один или два человека, ожидание является нормальным состоянием. Материалы можно посмотреть на главной через Preview the four-week plan.

## AI

Базовые программы работают без внешних сервисов. Для настоящей AI-адаптации скопируйте `.env.example` в `.env` и задайте:

```dotenv
AI_CHAT_ENDPOINT=https://your-provider.example/v1/chat/completions
AI_API_KEY=your-secret-key
AI_MODEL=your-model-id
```

Нужен провайдер с совместимым chat completions API и JSON-ответом. Перезапустите сервер после настройки. Ключ остаётся на сервере. Не вставляйте ключ в браузер, исходники, сообщения или Git. Неправильный ответ, таймаут и отсутствие настройки сохраняют доступ к базовой программе. AI не подбирает участников и не проверяет навыки. Успешно адаптированный план сохраняется; начатые задания не переписываются.

Для учебного трека AI предусмотрен бесплатный mock-провайдер в задании. Реальные API-вызовы в проектах участников требуют их собственного провайдера и могут иметь отдельную стоимость.

## Готовность и Google Meet

В Overview под ближайшей встречей каждый нажимает I’m ready и подтверждает, что готов подключиться сейчас. Подтверждение открывает отдельную вкладку ожидания, а кабинет команды остаётся открытым. Пока ждём остальных, готовность можно отменить. После подтверждения всех текущих участников сервер создаёт и сохраняет одну конференцию; вкладка ожидания автоматически открывает Meet. Если браузер блокирует новую вкладку, доступна кнопка ручного входа.

После звонка закройте вкладку Meet, чтобы вернуться к открытому кабинету. Нажатие «Завершить звонок» внутри Google не передаётся нашему сайту, поэтому автоматический возврат именно по этому событию не обещается.

Для автоматического создания один участник команды подключает Google. Настройка проекта, OAuth-клиента и серверного шифрования описана в [GOOGLE-MEET-SETUP.md](GOOGLE-MEET-SETUP.md). Без настройки приложение честно показывает необходимость подключения: готовность сохраняется, но выдуманная ссылка не создаётся. Обычная регистрация в Learning Squads по-прежнему не требуется. Google-подключение не восстанавливает потерянную гостевую cookie.

Готовность относится к конкретной встрече и текущему составу. Добавившийся участник подтверждает её сам; вышедшие не учитываются. Можно подтвердить готовность и раньше назначенного времени, если вся команда договорилась встретиться сейчас. Доступ к камере, микрофону и допуск в конференцию регулирует сам Google Meet.

Новые конференции создаются в режиме Open: по согласованному правилу любой обладатель Meet-ссылки может войти без запроса допуска. В самом Learning Squads ссылка на ближайшую встречу по-прежнему открывается текущим участникам только после готовности всей команды. Остальные правила Google и настройки организатора сохраняются.

## Проверки

```powershell
npm test
npm run build
```

HTTP-тесты используют отдельные базы и независимые cookie, проверяют сохранение после перезапуска, конкурентное вступление, границы доступа, расписание и смену времени, жизненный цикл и AI fallback. Инъекция времени в `createApp` позволяет проверять четыре недели без ожидания.

При передаче проекта 14 ноября 2026 года: 20 из 20 HTTP-тестов прошли, production-сборка успешна. В браузере проверены анкета → отсутствие совпадений → создание команды → восемь дат → сохранение задания → обновление страницы, валидация Meet-ссылки и экран шириной 390 px. Ошибок JavaScript в проверенном сценарии не обнаружено. Тестовые данные браузерной проверки хранятся отдельно от рабочей базы.

AI проверен на тестовых адаптерах (успех, ошибка, некорректный ответ и конкурентное сохранение задания); вызов реального провайдера требует настройки и пока не проверялся.

Обновление 15 ноября 2026 года: 35 HTTP-тестов проходят (20 исходных и 15 для автоматической очереди, отмены, срока поиска, DST, гонок и миграции номеров). При старте прежняя база обновляется без сброса профилей, членства или прогресса.

В браузере также проверена новая цепочка: анкета → Find my teammates → ожидание → автоматическое формирование команды из трёх тестовых участников → восемь дат → кабинет. Результат появляется без обновления страницы; ошибок JavaScript в проверенном сценарии нет. Эта проверка использовала отдельную базу данных.

Обновление готовности и Google Meet: проходят 57 автоматических тестов, включая 15 проверок готовности и 7 проверок Google OAuth. Проверены конкурентное создание конференции, отмена готовности, изменение состава и отключение организатора, права доступа и сохранение данных. Production-сборка успешна. В браузере проверены подтверждение и отмена готовности, общий счётчик и сохранение после обновления; ошибок JavaScript нет. Через общий HTTPS-адрес проверены три независимых участника и честное сообщение при отсутствии настройки Google. Автоматические тесты OAuth и создания конференций используют адаптеры.

15 ноября 2026 года на временном HTTPS-сервере также успешно завершено настоящее OAuth-подключение организатора и проверено сохранение зашифрованного доступа. Через тот же серверный Google Meet сервис создана отдельная настоящая тестовая конференция: API вернул корректные meetingUri и space name. Эта проверка не изменяла готовность участников или запланированные встречи. Полный сценарий автоматического перехода реальной команды требует, чтобы все её участники самостоятельно подтвердили готовность.

Дополнительно проверены отдельная вкладка ожидания, отмена и повторное подтверждение готовности, сохранение кабинета, автоматическое открытие настоящей Meet-страницы после готовности 3 из 3 и отказ открывать будущую встречу. Проверка выполнена на отдельной тестовой базе; браузерных ошибок не обнаружено. Для текущей реальной конференции режим Open установлен через Google API и подтверждён повторным чтением, ссылка сохранена. Создание новых конференций с Open покрыто проверкой тела API-запроса.

## Область первой версии

Цена $29 является информационной гипотезой. Основной сценарий бесплатен; настоящих списаний и автопродления нет. Аккаунты и восстановление после потери cookie, собственный чат и следующие платные спринты отложены согласно исходному описанию.

Гостевой доступ привязан к cookie этого браузера. После очистки cookie или перехода на другое устройство восстановить доступ в MVP нельзя.

Для постоянного публичного размещения нужен Node.js-сервер и постоянный диск для SQLite. Настройте HTTPS, `NODE_ENV=production`, точный `APP_ORIGIN` и резервные копии. Для проверки с друзьями используется временный HTTPS-туннель к локальному серверу: он доступен, пока компьютер включён и туннель работает. Постоянный хостинг и домен пока не настроены. Исходники: https://github.com/bigstep832/learning-squads (приватный репозиторий).

## Файлы

- `src/` — React интерфейс.
- `server/app.js` — HTTP API, база и правила доступа.
- `server/scheduling.js` — часовые пояса и проверка доступности.
- `server/matchmaking.js` — общее расписание и автоматическое формирование команды.
- `server/google-meet.js` — Google OAuth и создание конференций, зашифрованные серверные токены.
- `src/meeting-access.jsx` — готовность и автоматическое открытие общей конференции.
- `server/curricula.js` — программы трёх направлений.
- `tests/acceptance.test.js` — интеграционные проверки.
- `tests/matchmaking.test.js` — проверки очереди и автоматического подбора.
- `API-CONTRACT.md` — форматы запросов и ответов.
- `MATCHMAKING-CONTRACT.md` — обновление контракта для автоматического подбора.
- `MEET-CONTRACT.md` — готовность участников и API конференций.
- `GOOGLE-MEET-SETUP.md` — подключение Google Meet.

Параметры первой версии: четыре недели, 3–4 участника, две встречи по 50 минут внутри часовых окон, около двух часов самостоятельной практики в неделю. У каждого участника собственный проект; преподаватель не входит в формат.
